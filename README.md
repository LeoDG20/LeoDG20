## ◼ Projeto em destaque

<div align="center">

### 🎙️ Whisper Corpus Studio

</div>

Uma aplicação desktop desenvolvida em **Python** para curadoria de corpora de fala sussurrada. O projeto reúne segmentação fonética assistida, visualização de waveform e espectrograma, revisão de anotações, treinamento de modelos acústicos e exportação de datasets auditáveis e reproduzíveis.

**O projeto inclui:**

- segmentação assistida com possibilidade de desfazer operações;
- visualização de áudio por waveform e espectrograma;
- fluxo de revisão e anotação de segmentos;
- baseline acústico e inferência em áudio bruto;
- exportação de datasets com metadados para reprodutibilidade;
- testes automatizados e integração contínua.

**Tecnologias:** `Python` · `PySide6` · `SQLite` · `DSP` · `Machine Learning`
